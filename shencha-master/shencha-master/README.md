## 审查智能体

通过fast api提供server 服务

### 智能体

复制.env.example为.env并按照格式填写api_key


### 后端

```commandline
pip install -r requirements.txt
python app.py
```


### 前端

```commandline
cd frontend
npm install
npm run dev
```
